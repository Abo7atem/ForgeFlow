# ForgeFlow Lite v1.0.0

## Highlights
- Lightweight ForgeFlow release focused on video interpolation and enhancement.
- Drag and drop video input.
- Automatic output path beside the original video.
- Outputs two files only:
  - `Video 60FPS`
  - `TikTok30FPS`
- Real-ESRGAN and unused Pro tools removed for a smaller package.
- RIFE model: `rife-v4.26`.

## Protection
- 5 free trial runs, then activation is required.
- Separate ForgeFlow Lite license signing key from 4TikoTool Pro.
- Mandatory GitHub update gate before processing and activation.
- Encrypted license and trial state using AES-CBC + HMAC-SHA256.
- Multi-stage license/session checks during processing.
